✛CS598 / MPI heat diffusionMethods

An implicit step is a linear solve

∂T / ∂t = α ∇²T

Unit square, zero-temperature edges
N × N interior points

(I − αΔt Lh) x = b

b is the previous temperature field
x is the next temperature field

r = αΔt / h² with h = 1 / (N + 1)

Illinois Campus Cluster · Extended study 1231273502 / 12
Explain the PDE briefly, then focus on backward Euler. Each physical step creates a linear system A x = b. The matrix is symmetric positive definite for positive r, so CG applies. The diagonal is 1+4r and each present neighbor has coefficient −r. Outside-domain values are zero. The production solver never forms a dense matrix. Source: src/main.cpp:20–54 and report/report.md:5. Aim for 45 seconds.

Illinois Campus Cluster · Extended study 1231273504 / 12
Separate an iterative solver update from a physical time step. Both algorithms solve exactly the same backward Euler system. CG pays for two dot-product reductions on each update but normally needs fewer updates. Jacobi checks after update 1, every tenth update, and at the cap, so it can overshoot the earliest acceptable iterate. Initial norm and residual checks add work for both algorithms. Both finish with an independently recomputed true residual outside the timed interval. Source: src/main.cpp:73–99. Aim for 60 seconds.
